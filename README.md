# ai_meeting_notes_tracker
Description

This is a web app where you paste in your meeting notes, and it automatically:

1.Shortens them into a quick summary

2.Picks out the main points

3.Finds things people need to do (action items)

4.Saves everything so you can look back at old meetings later

Features

->Type or paste notes - just write your meeting notes in a box

->Get a summary the app picks the most important sentences and shows them
as a short summary

->See key points - a bullet list of the main things discussed

->See action items the app automatically spots sentences like "Sarah will do X" or "due by Friday" and lists them separately, so nothing gets missed

Save & view past meetings - every meeting you save stays in a list, and you can click on any old one to see it again or delete it

Technology Used

- Just simple, everyday web building blocks:

- HTML-builds the page (boxes, buttons, text)

- CSS-makes it look nice (colors, layout)

- JavaScript-does the thinking (makes the summary, finds action items, saves data)

Nothing fancy needed no internet connection to an Al server, no sign-up, no installing extra software. It all works right in your browser.

How to Run the Project

1. Unzip the project folder.

2. Open the folder in VS Code.

3. Just double-click index.html - it opens in your browser and the app runs immediately.

4. Type some notes, click the "Generate" button, then click "Save" if you want to keep it.

That's it-no setup steps, no passwords, nothing to configure.

Project Purpose

Meetings often produce long, messy notes that are hard to re-read later. This project

solves that by turning messy notes into something short and useful automatically - a summary, the key points, and a clear list of what needs to be done and keeps a history so you can always find a past meeting again.
